# السوق اليمني — نسخة أولية

واجهة عربية متجاوبة لمنصة إعلانات مبوبة تستهدف اليمن.

## الأقسام
- سيارات ومركبات
- جوالات وإلكترونيات
- عقارات
- أثاث ومنزل
- ملابس وإكسسوارات
- أخرى وخدمات

## التشغيل
افتح `index.html` في متصفح حديث، أو انشر مجلد `marketplace` كملفات موقع ثابت.

## الموجود حالياً
- تصميم متجاوب للهواتف والحواسيب.
- بحث نصي وتصفية حسب المدينة والقسم.
- نموذج إضافة إعلان.
- بيانات تجريبية للعرض.
- حفظ الإعلانات التي يضيفها المستخدم محلياً في المتصفح.

## تنبيه مهم
هذه نسخة واجهة أولية (MVP Frontend)، وليست منصة إنتاج مكتملة. الإعلانات المضافة محفوظة على نفس الجهاز والمتصفح فقط، ولا تظهر للمستخدمين الآخرين. لا يوجد حالياً تسجيل دخول أو قاعدة بيانات مشتركة أو رفع صور فعلي أو لوحة إدارة أو تحقق من أرقام الهاتف. يلزم ربط Backend وقاعدة بيانات وتخزين صور ومصادقة المستخدمين قبل الإطلاق العام.

اسم المنتج مؤقت ويمكن تغييره لاحقاً. العملة المعروضة في نموذج الإضافة هي الريال اليمني.
