# سوق السيارات | Car Market

مشروع تجريبي عربي لواجهة معرض سيارات مبني باستخدام HTML وCSS وJavaScript.

## المميزات
- عرض سيارات تجريبية مع الاسم والشركة وسنة الصنع والسعر والصورة.
- البحث بالاسم أو الشركة.
- تصفية السيارات حسب الشركة والسعر.
- إضافة إعلان سيارة جديد.
- حذف إعلان من القائمة.
- حفظ بيانات الإعلانات محليًا في المتصفح باستخدام `localStorage`.
- تصميم متجاوب للهواتف وأجهزة الكمبيوتر.

## تشغيل المشروع
افتح ملف `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت مكتبات أو خادم.

## ملفات المشروع
- `index.html`: هيكل الصفحة.
- `styles.css`: التصميم وتنسيق العرض.
- `script.js`: بيانات السيارات ووظائف البحث والإضافة والحذف.

## ملاحظة
هذه نسخة تعليمية تجريبية. بيانات السيارات المضافة تُحفظ على نفس المتصفح والجهاز فقط، ولا توجد قاعدة بيانات مشتركة أو حسابات مستخدمين أو نظام دفع. صور السيارات والخط تتطلب اتصالًا بالإنترنت.
